# Academic Nexus

## Overview

Academic Nexus is a cutting-edge application designed to serve as a digital academic mentor for students at Mumbai University. The app provides a high-tech, minimalist interface that enhances the learning experience through AI-driven insights, chat functionalities, and analytics.

## Features

- **AI Tutor Chat**: Engage in real-time conversations with an AI tutor to clarify doubts and receive guidance on various topics.
- **Trial Counter**: Keep track of your free queries and usage to manage your learning effectively.
- **Predicted Questions**: Get insights into likely questions based on your study patterns, complete with probability scores.
- **Locked Analytics**: Access advanced analytics features that help you understand your learning progress and areas for improvement.
- **Paywall Modal**: Unlock premium features for an enhanced learning experience.

## Installation

To get started with the Academic Nexus application, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/academic-nexus.git
   cd academic-nexus
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the application**:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000` to view the application.
